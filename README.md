# Healingarty Image Browser — ComfyUI

캔버스에 놓고 사용하는 이미지 탐색기 노드. 기존 **Load Image** 노드로 썸네일을 드래그하세요.

## 설치

ComfyUI의 `custom_nodes` 폴더에서:

```sh
git clone https://github.com/daning1212/Healinagarty-picture-brower-Drag-and-Drop.git
```

최초 설치 후 ComfyUI를 재시작하고 브라우저를 새로고침합니다. 캔버스 더블클릭 → `Healingarty Image Browser` 검색. 노드 오른쪽 아래를 드래그해 크기를 조절합니다. 별도 pip 패키지는 일반 ComfyUI 설치의 Pillow/aiohttp 외에 필요 없습니다.

## 사용

- 경로 입력 후 Enter 또는 **이동**. 폴더 버튼으로 이동, ← 뒤로, ↑ 상위, ⟳ 새로고침.
- **경로 지정**: 노드 안에 드라이브/input/output/홈 바로가기 표시. 폴더로 이동 후 **이 폴더 선택**. 운영체제 폴더 선택 팝업이 아닌 노드 내부 선택 방식입니다.
- **현재 경로 열기**: ComfyUI 실행 컴퓨터의 OS 파일 탐색기로 현재 폴더를 엽니다.
- **파일명 검색**, **썸네일 크기 80~220px** 슬라이더.
- **☆ 즐겨찾기** 추가. 즐겨찾기 우클릭으로 해제.
- 이미지 아래 파일명과 `640 × 480 · PNG` 표시. 크기는 EXIF 회전을 반영합니다.
- 썸네일을 기본 **Load Image** 위에 드롭하면 선택값과 미리보기를 갱신합니다. 노드 연결은 유지됩니다. 다른 노드나 빈 캔버스에 놓으면 아무것도 불러오지 않습니다.
- 마지막 폴더·썸네일 크기·즐겨찾기는 같은 브라우저/사이트에 저장됩니다.

탐색 경로는 **ComfyUI 서버 컴퓨터** 기준입니다. Windows 드라이브, 한글, 공백 경로를 지원하며 실행 계정의 파일 권한이 적용됩니다. 폴더 변경에는 재시작이 필요 없습니다. 원격 서버에서는 `현재 경로 열기`도 서버에서 실행되며, GUI 없는 서버에서는 실패할 수 있습니다.

## 파일 보존과 성능

원본은 수정하지 않습니다. input 밖의 이미지는 드롭할 때만 `input/healingarty_browser/`에 복사합니다. 경로·수정시각·파일크기 기반 이름으로 충돌을 방지하고 동일 파일 재사용 시 중복을 줄입니다. PNG 워크플로 메타데이터는 보존하지만 드롭 시 워크플로 로더를 호출하지 않습니다.

목록은 80개 단위로 표시하고 **더 불러오기**로 이어서 봅니다. 썸네일은 화면 근처 항목만 최대 4개씩 요청합니다. 폴더 이동 시 이전 요청을 취소합니다. 폴더 목록 정렬을 위해 디렉터리 전체의 파일명은 스캔하므로, 아주 큰/느린 네트워크 폴더는 첫 목록까지 시간이 걸릴 수 있습니다.

삭제·이동·일반 파일 복사 기능은 없습니다. 기본 Load Image 사용에 필요한 복사만 수행합니다.

## 검증 및 범위

```sh
python -m unittest discover -s tests -v
node --input-type=module --check < web/browser.js
```

백엔드는 폴더 페이지/검색, 이미지 크기, 원본 보존, 중복 복사 방지, 잘못된 이미지 거부를 테스트합니다. 프런트엔드는 ComfyUI의 extension API, DOM widget, 기본 image widget callback을 사용합니다. 실제 Windows ComfyUI의 드래그·미리보기·캔버스 UI는 설치 후 확인이 필요합니다. 기본 LiteGraph 캔버스를 우선 대상으로 하며 실험적 Vue 노드 렌더러/서브그래프와의 호환성은 아직 검증하지 않았습니다.

이 확장은 서버 계정이 접근 가능한 임의 폴더 탐색 및 OS 폴더 열기 API를 제공합니다. 신뢰할 수 있는 로컬 ComfyUI 환경용이며 인증 없는 서버를 인터넷에 공개하지 마세요.
